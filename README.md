Skici, bilgisayarınızdaki tüm dosyaları ve klasörleri geri döndürülemez şekilde silen, tek tıkla çalışan bir temizleme aracıdır.

🚀 Özellikler
✅ Tek Tıkla Temizlik: Karmaşık komutlara gerek yok
✅ Çapraz Platform: Windows, Linux, Mac desteği
✅ Yönetici Kontrolü: Gerekli yetkileri otomatik kontrol eder
✅ Kullanıcı Onayı: Yanlışlıkla çalıştırmayı önler
✅ Hızlı ve Etkili: Sistemdeki her şeyi anında temizler
🎯 Nasıl Çalışır?
Programı çalıştır
Uyarı mesajını oku
"Evet" derse: 💥 BOOM! Her şey gider
"Hayır" derse: Program kapanır, sistem güvende kalır
📥 Kurulum
bash
git clone https://github.com/kullanici-adin/nuke-tool.git
cd nuke-tool
python dosya_silici.py
⚡ Kullanım
Windows:

cmd
python dosya_silici.py
# Yönetici olarak çalıştırın!
Linux/Mac:

bash
sudo python dosya_silici.py
# Root yetkisi gerekli!
